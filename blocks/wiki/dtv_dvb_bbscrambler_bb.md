Scrambles FEC baseband frames with a PRBS encoder.

Input: Variable length FEC baseband frames (BBFRAME).

Output: Scrambled variable length FEC baseband frames (BBFRAME).

## Parameters
- Standard
  DVB standard (DVB-S2 or DVB-T2).

- FEC Frame Size
  FEC frame size (normal, medium or short).

- Code Rate
  FEC code rate.
